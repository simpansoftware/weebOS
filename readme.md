# weebOS
weebOS is a webOS i made for Hack Club Macondo
## Features
- There's a taskbar at the top that shows the time
- Multiple windows at the same time
- Draggable windows
- Protection to make sure you dont drag a window outside of the screen
- proxy application, which is another project of mine
